## Phase Goal (MVP user story)

**As a** TRAP2 neuroscience researcher, **I want to** run one numbered script that classifies the detected M3 hippocampus nuclei into TdT+/Fos+/Double+/Negative and tags each with its Allen CCFv3 region, **so that** I get atlas-registered, biologically-interpretable cell classes from a single section as the runnable spine of the pipeline.

> Note (surfaced discrepancy): the ROADMAP Phase 3 `**Goal:**` line is outcome-shaped, not literal "As a…" user-story form. The story above is a faithful derivation of that goal, consistent with how Phases 1–2 (also `Mode: mvp`) were planned; it was not invented.

<objective>
Deliver the thinnest runnable end-to-end slice: `02_detect_classify.groovy` that classifies the BraiAnDetect-produced nuclei on the M3 entry into TdT+/Fos+/Double+/Negative, attaches an atlas region label to each cell, and writes a classified `data.qpdata`. This is the working spine that Plans 02 (reporting) and 03 (background-robust measure) refine.

Per **D-01**, this script does NOT detect — detection stays in `run_braian_detection.groovy`; this numbered script is the classify/label/report entry point that assumes detections already exist. Per **D-02**, it guards on zero detections and re-classifies in place idempotently.

Purpose: Satisfy SC1 (script runs, writes classified `data.qpdata`) and the four-class + atlas-label parts of SC2 on the working (raw-measure) classification path, before any robustness refinement.
Output: `scripts/02_detect_classify.groovy` + its project-local hard-copy, deployed for QuPath "Run for project".
</objective>
