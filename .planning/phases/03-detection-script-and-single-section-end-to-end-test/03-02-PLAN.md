## Phase Goal (MVP user story)

**As a** TRAP2 neuroscience researcher, **I want to** read per-subfield TdT+/Fos+/Double+/Negative counts in the QuPath annotation pane and confirm my cell coordinates are in Allen CCFv3 microns, **so that** the classified section is immediately interpretable and I can trust the atlas registration units before scaling to the series.

No new detection or classification logic — these are read-only reporting slices on top of the existing working script.

Output: extended `scripts/02_detect_classify.groovy` + project hard-copy.
</objective>
