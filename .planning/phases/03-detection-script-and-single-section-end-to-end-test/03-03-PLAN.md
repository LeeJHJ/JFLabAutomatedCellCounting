## Phase Goal (MVP user story)

**As a** TRAP2 neuroscience researcher, **I want to** classify Fos and TdT on a local-background-subtracted measure whose thresholds are re-derived from the section's own distribution, **so that** regional autofluorescence (e.g. SSp reading ~2× AF488) no longer produces false-positives and the classifier is series-ready before the full batch run.

<objective>
Refine the working classification slice with the phase's crux capability: a compartment-agnostic local-background-subtracted intensity measure (D-04) and re-derived positive thresholds on that measure (D-05), then wire the compound classification to use them. This is the robustness/edge-case refinement of the runnable path from Plans 01–02 — it fixes the Phase-2 Deviation #2 SSp-autofluorescence false-positive without changing the hippocampal CA1/CA2/CA3/DG classification topology.

Per **D-03**, this is built now (not deferred) so the classifier is series-ready even though SSp false-positives land outside the Phase-3-validated subfields. Per **D-04**, the mechanism is local-background subtraction — compartment-agnostic (nucleus ring for Fos, expanded cell/cytoplasm ring for TdT, extensible to a future PNN pericellular annulus) — NOT a nucleus:cytoplasm contrast ratio. Per **D-05**, thresholds are re-derived on the new measure via the same histogram-relative philosophy locked in Phase 2; the old absolute cutoffs (13000.4538 / 16766.4671) are superseded but kept as documented reference.

Purpose: Make the classifier autofluorescence-tolerant and series-ready (D-03/D-04/D-05) while keeping SC1/SC2/SC3/SC4 true.
Output: extended `scripts/02_detect_classify.groovy` (+ project copy) and new bg-sub classifier JSON(s).
</objective>
