<objective>
Gate the 5-section series on two human confirmations that no automated assertion can make:
(1) each output MIP is a single, intact coronal section correctly mapped scene->s{N} (CONV-02),
and (2) the physical channel index -> marker (TdTomato vs Fos) assignment is correct on this
new CZI (CONV-01 / RESEARCH Assumption A1). Both are visual/knowledge checks the operator at
the microscope must make before the series is trusted.

Purpose: RESEARCH independently confirmed physical index 2 = DAPI on this file, but could NOT
distinguish which of index 0 vs 1 is TdTomato vs Fos by density/pattern alone (both are sparse
reporter channels in recall-reactivated tissue). The `--channels "TdTomato-AF568" "Fos-AF488"
"DAPI"` override is inherited from the M3 acquisition, not independently re-derived for this
file. If it is wrong, TdT+/Fos+ labels swap in every downstream classifier — a repeat of the
`feedback_channel_order.md` bug class. This checkpoint closes that gap before Phase 8.

Output: operator approval (or a documented correction to `--channels` if the assignment is
wrong, triggering a re-run of plan 05-01 with the corrected order).

This plan is Wave 2 — it depends on plan 05-01 having produced the 5 MIPs + 5 identity PNGs.
Per the checkpoint-separation convention it carries no implementation, only the blocking human
gate.
</objective>
