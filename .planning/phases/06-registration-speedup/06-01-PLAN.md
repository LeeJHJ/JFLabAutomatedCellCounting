Author the three executor-owned, self-testable pieces the REG-05 masked-elastix single-section
trial needs: (1) `scripts/extract_atlas_plate.py`, which pulls a single Allen CCFv3 coronal
plate (+ its binary mask) at a given AP position via brainglobe-atlasapi to serve as elastix's
fixed image; (2) the two standard elastix parameter maps `Par_Affine.txt` / `Par_BSpline.txt`;
and (3) `scripts/elastix_trial_harness.py`, a `subprocess.run([...], shell=False)` wrapper that
constructs the verified `elastix -f/-m/-fMask/-mMask/-p/-out` and `transformix -in/-tp/-out`
command lines. All three ship with a `--self-test` running on SYNTHETIC data only (no ~1GB atlas
download, no real elastix run).

means the operator's later single-section elastix trial (plan 06-05, D-06/D-07) is a matter of
running already-correct tools on the one worst-fitting section, not writing code mid-trial.

`scripts/elastix_params/Par_BSpline.txt`, `scripts/elastix_trial_harness.py` — each green under
