## Decisions Made

- Compartment→label map fixed as `nuclear`→`Nucleus`, `cytoplasmic`→`Cytoplasm`; bg-sub measurement key format locked as `"<label>: <channel> mean (bg-sub)"` — this is the exact string every downstream groovy classify/export consumer must reproduce (06.1-02, 06.1-03)
- Per-slice column set = `region, hemisphere, is_leaf, area_mm2, <anchor>_count, <anchor>_density`, then `<marker>+_count`/`<marker>+_density` per declared marker, then `Double+_count`/`Double+_density` only when ≥2 non-anchor markers are declared — built entirely from the config's `markers` list, never a fixed array
- `pipeline.yml` defensively checked (in `load_config`) for accidental presence of any BraiAnDetect detection-param key (`sigmaMicrons`, `minAreaMicrons`, `maxAreaMicrons`, `histogramThreshold`, `cellExpansionMicrons`) to keep D-14's separation from `BraiAn.yml` enforced by the validator itself, not just by convention
