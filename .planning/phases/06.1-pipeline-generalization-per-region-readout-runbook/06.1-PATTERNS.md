**Nucleus-anchored compartment resolution — the exact hook to parameterize (lines 171-208, `localBackgroundSubtractedMean`):**
```groovy
def localBackgroundSubtractedMean = { baseRoi, String channelName, selfDetection ->
    try {
        def innerRoi = RoiTools.buffer(baseRoi, gapPx)
        def outerRoi = RoiTools.buffer(baseRoi, outerPx)
        def annulusRoi = RoiTools.subtract(outerRoi, innerRoi)
        def region = ImageRegion.createInstance(annulusRoi)
        def neighborRois = hierarchy.getAllObjectsForRegion(region)
                .findAll { it.isDetection() && it != selfDetection }
                .collect { it.getROI() }
                .findAll { it != null }
        def cleanAnnulus = neighborRois.isEmpty() ? annulusRoi : RoiTools.subtract(annulusRoi, neighborRois)
```

**CR-01 geometric leaf resolution + parent-rollup precondition (D-10) — reuse verbatim from `03_export_val01_metrics.groovy` lines 68-104:**
```groovy
def regionAnnotations = getAnnotationObjects().findAll { ann ->
    def roi = ann.getROI()
    if (roi == null) return false
    if (ann.getChildObjects().any { it.isDetection() }) return false
    def lbl = ann.getPathClass()?.toString() ?: ann.getName()
    lbl != null && lbl != "AllDetections"
}
def regionAnnotationsByArea = regionAnnotations.toSorted { it.getROI().getArea() }
def regionOf = { detection ->
    def r = detection.getROI()
    double x = r.getCentroidX(), y = r.getCentroidY()
    regionAnnotationsByArea.find { it.getROI().contains(x, y) }   // smallest containing = true leaf
}
def isLeafOf = { ann ->
    def roi = ann.getROI()
    double a = roi.getArea()
    !regionAnnotations.any { other ->
        if (other.is(ann)) return false
        def oroi = other.getROI()
        oroi.getArea() < a && roi.contains(oroi.getCentroidX(), oroi.getCentroidY())
    }
}
```
**D-10 rollup implementation note (critical, not present verbatim in any existing script — planner must add new code, not just copy):** `regionOf` already assigns every cell to exactly one leaf (CR-01, D-10's "every cell assigned to exactly one leaf" requirement is satisfied by this exact closure — do not re-derive). What's NEW for D-10 is the **parent rollup**: after leaf counts are tallied, walk the Allen atlas ancestor tree (parent annotations, resolved via `resolveHierarchy()` already called in `01_load_abba_rois.groovy`) and SUM descendant-leaf counts upward — never re-run `regionOf`-style centroid-in-parent-ROI counting independently for parent rows (that would double-count / reintroduce the exact CR-01 leak). Use QuPath's already-resolved annotation parent/child hierarchy (`ann.getParent()`) to walk up, not geometry, once leaf assignment is done.

**Per-entry non-clobbering filename stem — reuse verbatim for the per-slice table output (`03_export_val01_metrics.groovy` lines 158-178):**
```groovy
def invalidChars = (['<', '>', ':', '"', '/', '\\', '|', '?', '*'] as Set)
    .collect { java.util.regex.Pattern.quote(it) }.join('|')
def entry = getProjectEntry()
def rawName = (entry != null ? entry.getImageName() : getCurrentImageData().getServer().getMetadata().getName())
def safeName = (rawName != null ? rawName : "").replaceAll(invalidChars, '')
def entryId = (entry != null ? entry.getID() : "").replaceAll(invalidChars, '')
def stem = (entryId != null && !entryId.trim().isEmpty()) ? "${safeName}__id${entryId}" : safeName
if (stem == null || stem.trim().isEmpty()) {
    throw new RuntimeException("sanitized entry stem is empty -- refusing to write an unnamed export file")
}
```

**D-04 schema-omission ("TdT-only ⇒ DAPI+/TdT+ only, no NA columns"):** implement by building the per-slice table's column set (and the long/tidy rows) purely by iterating the config's declared marker list — never iterate a fixed `["Fos","TdT"]` array. On a single-non-anchor-marker config, the row-emission loop for `class="Double+"` combinations is simply skipped (D-03's ≥2-marker gate), producing zero Double+ rows by construction rather than by a post-hoc filter.

**Per-cell TSV role folded in (D-07):** reuse the per-cell row-building loop from `03_export_val01_metrics.groovy` lines 131-198 (region label via `regionOf`, nucleus area from ROI geometry not a stored measurement, bg-sub measurement keys read via `numOrNaN` null-guard) — generalize the fixed `fosKey`/`tdtKey` two-column read into a loop over declared markers' bg-sub measurement keys (same naming convention `"${compartment}: ${channel} mean (bg-sub)"` that `02_detect_classify.groovy` writes).
