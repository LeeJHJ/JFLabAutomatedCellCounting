## Goal achievement

The pipeline is now a **single config-driven implementation** (one classify script, one export script) whose behavior is fixed by `pipeline.yml`. It was exercised end-to-end on a genuinely new, **single-marker (TdT-only)** slice set and degraded cleanly — zero Fos/Double+ artifacts — producing biologically plausible amygdala engram fractions (BMA>BLA>LA, ~4–8% across k). The variable-marker requirement (the central risk of the phase) is empirically satisfied. Runbook + launcher deliver the reuse requirement.

Real-data validation additionally hardened the pipeline via fixes surfaced only by running it (zero-leak edge-cell reconciliation, whole-cell TdT compartment + two propagation fixes, dim-DAPI detection tuning, k-sweep tooling).
