# Quick Task 260729-qc8: Operator-tunable pipeline parameters

## Goal

Every tuning knob reachable and adjustable from one place, so the operator can iterate
without editing source. Configs stay split on disk (D-14 intact); comments survive
writes; each tuning round is recorded.

## Key finding that shapes the plan

`ruamel.yaml` is **NOT installed** in the `braian` env (verified 2026-07-29:
`ModuleNotFoundError`; PyYAML 6.0.3 and pandas 2.3.3 are present). A PyYAML
`safe_load` → `safe_dump` round-trip would strip every comment out of `BraiAn.yml` and
`pipeline.yml`, destroying the tuning rationale those comments carry (why `span_frac`
is 0.25, why `sigma` 2.0 vs 2.5, why `classifiers:` is empty by design).

**Therefore:** read values with PyYAML (safe, read-only); WRITE by targeted
line-level scalar substitution that preserves indentation, inline comments, and every
untouched byte. Round-trip fidelity is a `--self-test` assertion, not an assumption.
No new dependency is added (CPU-only box, three fragile isolated envs — adding
ruamel to `braian` for a config writer is not worth the blast radius).

## Tasks

### Task 1 — `czi_mip.py`: expose the unreachable knobs

**files:** `czi_mip.py`

**action:**
- `--feather-margin INT` (default `DEFAULT_FEATHER_MARGIN` = 130) — seam blend width
- `--no-flat-field` — disable the currently-unconditional retrospective shading correction
- `--dapi-z N` — force the anchor focus plane; omitted = auto var-of-Laplacian (unchanged default)
- `--scenes N [N ...]` — 1-based scene subset; omitted = all scenes (unchanged default)
- Thread `feather_margin` / `flat_field` through `_read_channel_stacks_tiles` →
  `_stitch_scene_tiles` / `_apply_shading`; thread `force_z` through
  `_hybrid_scene_projection` → `_sharpest_plane_from_stack`.
- Flat-field and feather apply only to the `tiles` isolation path (`read_mosaic` does its
  own stitching), so warn loudly if they are passed under `--isolate region` rather than
  silently ignoring them.

**verify:** `--self-test` green, extended to cover forced-Z, flat-field-off, and a
non-default feather margin. Defaults omitted ⇒ behaviour byte-identical to today.

**done:** all four flags work; `--scenes 3` re-cuts one scene only.

### Task 2 — `scripts/cockpit_tune.py`: the control surface

**files:** `scripts/cockpit_tune.py` (new)

**action:** one knob registry spanning all three stages. `--list` (table: stage, knob,
current, source, effect, direction), `--set knob=value` (repeatable; routes to the
correct file; prints `old -> new`), `--log` (append round to
`<project>/results/tuning_log.csv`, sourcing numbers from the existing
`cockpit_qc_summary.csv` / `cockpit_readout.csv` — never recomputed), `--self-test`.

MIP knobs are CLI-only and must be shown as "pass to czi_mip.py", not as settable.

After a `--set`, run `validate_pipeline_config.py` and deploy via `sync_project.py`.

**verify:** `--self-test` proves comment-preserving round-trip on a fixture containing
comments, inline comments, and nested keys; `--list` against the real M3 Hipp1 project.

**done:** operator can see and change every knob from one command.

### Task 3 — notebook section + docs knob table

**files:** `notebooks/01_calibrate.ipynb`, `docs/tuning.md`, `mkdocs.yml`

**action:** notebook section exposing list/set/log (the cockpit is the established
operator surface); one docs reference table of every knob with default, effect, and
which direction to move it.

**verify:** notebook cells execute; `docs/tuning.md` linked in `mkdocs.yml` nav.

**done:** both surfaces reachable without reading source.
